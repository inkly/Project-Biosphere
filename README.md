# Project Biosphere

Un jeu de ferme et d'enquête génétique, seul ou à plusieurs : vous croisez des plantes pour obtenir celle qu'on vous demande.

Ce dépôt ne contient que les versions publiées du jeu (onglet **Releases**), pas son code.

## Jouer

1. Téléchargez le zip de la dernière version dans **Releases** (Windows 10 ou 11, 64 bits).
2. Décompressez-le, puis lancez `ProjectBiosphere.exe`. Rien à installer.
3. Windows peut afficher « Windows a protégé votre ordinateur » : le jeu n'est pas signé. Cliquez sur « Informations complémentaires », puis sur « Exécuter quand même ».

Le `LISEZ-MOI.txt` du zip donne les commandes, la sauvegarde et le jeu à plusieurs.

## Mises à jour

Une fois le jeu installé, l'écran d'accueil annonce les nouvelles versions et les installe sur un clic. Rien ne s'installe sans vous.

## Vos retours

Après votre partie, remplissez `QUESTIONNAIRE.txt` (dans le zip) et renvoyez-le à la personne qui vous a envoyé le jeu.
